## M0b — TDD order (one red test at a time)

Do not skip ahead. Each line is: write failing test → minimal code → refactor.

### Value types (Swift)

1. `Frame` 2×2 BGRA, stride, dirty rect full-frame default — unit tests, no protocol yet.
2. `InputEvent` key/mouse enums — round-trip equality tests.

### C ABI + StubEngine (Rust or C, no IronRDP)

3. `mrdpd_engine_abi_version() == 1` (T1-GFX-01 adjacent / ABI infra).
4. `start` on free port succeeds; second start → `ALREADY_STARTED`; `stop` idempotent; start/stop/start (T1-SEC-04 bind as much as a dummy listen).
5. `start` on bound port → `BIND`.
6. `push_frame` 2×2 BGRA succeeds; poison-after-return test in `docs/abi.md` (T1-GFX-01).
7. `push_frame` before start → `NOT_STARTED`.
8. Stub-only scripted mouse callback **or** `mrdpd_engine_test.h` — Swift will need one callback in step 11. Keep production ABI clean.

### Swift protocols (ISP: only these two)

9. `FrameSource` contract on `SyntheticFrameSource`: one 2×2 frame, expected stride (T1-GFX-01).
10. `InputSink` contract on `RecordingInputSink`: records one key-down (T1-IN-01).

### EngineKit wiring

11. Load StubEngine, `start`, push one synthetic frame, observe one scripted input callback (composition of B2+B3+B4 stubs).
12. `just test` runs Swift tests + ABI tests against StubEngine. No ScreenCaptureKit.

### Smoke executable (optional, still M0)

13. Tiny Swift CLI that starts StubEngine and prints “listening” — not a product.
