# V0 tasks — probe: one iPad session that answers the open questions

Gate for the viewport track ([milestones.md](../milestones.md)). One sitting with the iPad Pro and its external 4K monitor finishes the M6 survival gate and turns the unknowns in [spike R16](../spikes/2026-10-04-r16-clients-and-prior-art.md) into facts. No new product features.

## Build (before the session)

1. [ ] Engine logs a **capability line** on each connect (T1-VP-02, T1-GFX-07 evidence; no ABI change, log only): client name and build, requested desktop size, GCC monitor list, keyboard type and layout, whether DISPLAYCONTROL and EGFX were opened, and the EGFX CapsAdvertise versions and flags (AVC420 present or `AVC_DISABLED`). EGFX needs the `egfx` feature compiled in, but not used for frames yet.
2. [ ] `mrdpd-probe` (from `just live-check`) runs during the session to record exactly which keys and modifiers reach the Mac.

## Device checklist (owner, Windows App on iPadOS)

Record answers in the interop log below.

1. [ ] **M6 input.** Click, double-click, right click, drag, scroll, typing a paragraph, Cmd shortcuts. Score each pass or fail.
2. [ ] **Requested size.** Connect full screen on the iPad, then on the 4K (Stage Manager window maximized). What desktop size does each request (capability line)?
3. [ ] **Resize.** Resize the Stage Manager window. Does an RDPEDISP layout arrive (capability log)?
4. [ ] **Two windows.** Stage Manager → ••• on the Windows App window. Is there a "New Window" (two sessions visible at once, one on each screen)? If not, can two connections run at all, switching between them?
5. [ ] **Cmd mapping.** With `mrdpd-probe` in front, press Cmd+C, Cmd+Tab, Cmd+Space, Ctrl+C. What does the Mac receive?
6. [ ] **Hotkey passthrough.** Press Ctrl+Option+1, Ctrl+Option+[, Ctrl+Option+0. Do they reach the Mac unchanged (probe log)?
7. [ ] **H.264.** Does the capability line show AVC420 support?
8. [ ] **External display without Stage Manager.** Session on the 4K at native size, iPad as trackpad: usable?
